# shosu-app

4年「12 小数の表し方やしくみを調べよう」の学習アプリ（第1〜10時の「みる」「れんしゅう」と「ふくしゅう」）。

- 答えは□のマスに手書きする。数字（0〜9）だけを端末の中で読み取って丸をつける（通信なし）。
- 読みまちがいのときは「読みまちがい？」から、子どもが答えを見て自分で○×をつけられる。
- 先生メニュー：ホーム右上の歯車を1.5秒長押し（丸つけ方式、大きい文字、記録の確認・リセット）。

## もんだいづくり
- ホーム「もんだいをつくる」：筆算・文章題（問題文は手書き）・大小くらべ・ますの図・数直線。答えは数字キーで入れる。
- できあがったら「みんなに見せる」（大型モニター用の提示画面）、「リンクをコピー」（Teams・Classroom に貼る）、「ほぞん」。
- リンクを開くと提示画面になり、「自分で解く」で手書きで解いて丸つけできる。問題はリンクの中に入っていて、サーバーには保存されない。
- 先生は「もんだいボックス」に、集まったリンクをチャットの文章ごと貼ると一覧になり、順番に提示できる。

## 公開（GitHub Pages）
リポジトリの Settings → Pages で、公開するブランチとフォルダ（/root）を選ぶ。`index.html` を開けば動く（ビルド不要）。一度開けばオフラインでも使える。

## 開発メモ
- 計画: `PLAN.md`、部品の約束: `docs/CONTRACTS.md`
- 問題データの検査: `node tools/check-lessons.js`
- リンク共有の検査: `node tools/share-test.js`
- 読み取りの確認ページ: `tools/recognizer-test.html`
- 認識モデルの作り直し: `tools/train-digits.js`（先頭コメント参照）
